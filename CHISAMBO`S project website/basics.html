Basics of HTML

What is HTML?

HTML (HyperText Markup Language) provides the structure of web pages using elements (tags). Browsers read HTML and render the page.

Document structure

A minimal HTML document:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Page title</title>
  </head>
  <body>
    <h1>Hello</h1>
  </body>
</html>

Common elements

  • Headings: <h1> — <h6>
  • Paragraph: <p>
  • Links: <a href="...">link</a>
  • Images: <img src="..." alt="...">
  • Lists: <ul> / <ol> and <li>
  • Forms: <form>, <input>, <label>, <button>
  • Sections: <section>, <article>, <aside>, <nav>, <footer>

Attributes

Elements can have attributes that provide extra information. Example:

<a href="https://example.com" target="_blank">Visit example</a>

Images

Always include an alt attribute for accessibility:

<img src="cat.jpg" alt="A small cat sitting on a chair">

Lists

Unordered and ordered lists:

<ul>
  <li>Item one</li>
  <li>Item two</li>
</ul>

<ol>
  <li>First</li>
  <li>Second</li>
</ol>

Tables

<table>
  <thead>
    <tr><th>Name</th><th>Score</th></tr>
  </thead>
  <tbody>
    <tr><td>Afa</td><td>95</td></tr>
  </tbody>
</table>

Forms

Collect user input with forms:

<form action="/submit" method="post">
  <label>Name<input name="name" type="text"></label>
  <button type="submit">Send</button>
</form>

Semantic elements

Use semantic tags to describe meaning: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>.

Inline vs block

Block elements (like <div>, <p>) start on a new line. Inline elements (like <span>, <a>) flow within a line.

Example: small page

<!DOCTYPE html>
<html>
  <head><title>Demo</title></head>
  <body>
    <h1>My page</h1>
    <p>This is a simple paragraph with a <a href="#">link</a>.</p>
  </body>
</html>

CSS Basics

What is CSS?

CSS (Cascading Style Sheets) controls the visual appearance of web pages. It styles HTML elements with colors, fonts, layouts, and more.

Semantic Tags

Semantic tags are HTML elements that convey meaning about their content, in other words , they help describe the structure and meaning of content . — for example <header>, <nav>, <main>, and <footer>. They improve accessibility and SEO, and make styling clearer because you can target elements that describe their purpose.

THREE WAYS TO STYLE WITH CSS

  1. Inline CSS: directly in an element's style attribute.
  2. Internal CSS: in a <style> tag in the <head>.
  3. External CSS: in a separate .css file (recommended).

SELECTORS

CSS selectors target HTML elements:

/* Element selector */
p { color: blue; }

/* Class selector */
.box { background: yellow; }

/* ID selector */
#header { font-size: 2rem; }

/* Universal selector */
* { margin: 0; }

/* Attribute selector */
input[type="text"] { border: 1px solid gray; }

TYPOGRAPHY

Typography controls font, size, spacing, and text layout. Examples:

/* Base paragraph */
p { font-family: Arial, sans-serif; font-size: 1rem; line-height: 1.6; color: #222; }

/* Headings */
h1 { font-size: 2.25rem; font-weight: 700; line-height: 1.1; }
h2 { font-size: 1.75rem; font-weight: 600; }

/* Relative units (rem/em) */
html { font-size: 100%; } /* typically 16px */
small { font-size: 0.875rem; }

/* Responsive heading with clamp() */
h1.responsive { font-size: clamp(1.5rem, 2.5vw, 2.5rem); }

/* @import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap'); */

/* Utility for readable measure */

Box Model

Every element has margin, border, padding, and content:

div {
  margin: 10px;      /* outside space */
  border: 2px solid #333;
  padding: 15px;     /* inside space */
  width: 200px;
  height: 100px;
}

Flexbox Layout

Use flexbox to arrange items in a row or column:

.container {
  display: flex;
  justify-content: space-between;  /* horizontal */
  align-items: center;             /* vertical */
  gap: 1rem;
}

.item { flex: 1; }

Grid Layout

Use grid for complex 2D layouts:

.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 1rem;
}

.grid-item { grid-column: 1 / 3; }

Positioning

/* Static (default) */
div { position: static; }

/* Relative to normal position */
div { position: relative; top: 10px; }

/* Fixed to viewport */
nav { position: fixed; top: 0; }

/* Absolute within parent */
div { position: absolute; left: 50px; }

Transitions and Transforms

button {
  background: blue;
  transition: background 0.3s ease;
}

button:hover {
  background: darkblue;
  transform: scale(1.05);
}

Pseudo-classes

/* Link states */
a:hover { color: red; }
a:visited { color: purple; }

/* Form states */
input:focus { border-color: blue; }
button:active { opacity: 0.8; }

/* Structural */
li:first-child { font-weight: bold; }
p:nth-child(2) { color: gray; }

Media Queries (Responsive)

/* Desktop styles */
.container { width: 1200px; }

/* Mobile styles */
@media (max-width: 600px) {
  .container { width: 100%; }
  .card { flex-direction: column; }
}

Exercises

  1. Style a simple card with background, border, padding, and shadow.
  2. Create a flexbox navbar with centered items.
  3. Build a responsive grid layout that stacks on mobile.
  4. Add hover effects to buttons and links.
  5. Use CSS variables (--color: red;) for reusable values.
